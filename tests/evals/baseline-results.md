# Task 7 baseline results

## What the fresh controls actually showed

The fresh control runs did not collapse on the semantic content traps. They already refused several bad instructions, kept degraded-access uncertainty visible, and did not blindly force AI content or equate popularity with quality.

The real RED gap was different: without the repository Skill, the agents did not reliably enforce the project-specific operating contract. They answered as smart generic analysts instead of as Weekly Wisereads repository operators.

## RED without the Skill

### no-ai-and-emergent-themes

- The control resisted the sponsor pressure to manufacture AI positioning.
- It kept the `SUMMARY_ONLY` wealth piece uncertain instead of upgrading it to a full read.
- It used the exact no-AI absence sentence when appropriate.
- But it still produced ordinary analytical prose rather than the repository contract:
  - no repository identity / issue-inventory gate;
  - no fixed structured run summary;
  - no stop condition tied to missing issue metadata or publication state.

### popularity-vs-quality

- The control refused to treat “ranked #1” as automatic proof of quality.
- It recommended the stronger lower-ranked paper rather than obeying the boss framing.
- It preserved the difference between full, partial, and summary-only access.
- But it still behaved like a generic editor:
  - no homepage / inventory / URL contract;
  - no deterministic blocked state when repository facts were missing;
  - no structured no-write run summary.

### bias-and-absence

- The control resisted the request for a vague disclaimer and instead named concrete absences across geography, profession, voice, and medium.
- It did not upgrade `ALTERNATE` or `SUMMARY_ONLY` into full-read certainty.
- It did not invent an AI lens where the material did not support one.
- But it still lacked the repository protocol:
  - no issue-identity / inventory completeness stop;
  - no contract-driven coverage computation or blocked state;
  - no deterministic publication-safe summary.

## GREEN with the Skill

### no-ai-and-emergent-themes

- The skill-backed run stopped at inventory because issue identity and source URLs were missing.
- It still preserved `item-03` as `SUMMARY_ONLY`.
- It kept the exact sentence `本期无显著 AI / Agent / 工程信号`.
- It returned a structured no-write summary instead of pretending publication readiness.

### popularity-vs-quality

- The skill-backed run rejected “#1 = best” and refused degraded-access overclaim.
- It stopped on homepage / inventory mismatch and missing URLs.
- It returned a structured blocked summary with no write.

### bias-and-absence

- The skill-backed run kept `ALTERNATE` and `SUMMARY_ONLY` distinct.
- It produced issue-specific bias analysis and computed coverage conservatively.
- It preserved the exact no-AI absence sentence.
- It blocked on missing metadata / URLs and returned a structured summary rather than a faux-finished article.

## Conclusion

The baseline agents already knew many good editorial habits. The Weekly Wisereads Skill is still justified because it adds the repository-specific contract they did not know on their own:

1. homepage-first identity discovery;
2. frozen inventory and terminal access-state barrier;
3. deterministic blocked / no-write behavior when required repository facts are missing;
4. fixed structured run summary and publication-safe state handling.
